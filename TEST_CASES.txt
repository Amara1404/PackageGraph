re-flag or revisit Vulnerabilities page to see the updated count).


4. SANITY CHECKS
-------------------------------------------------------------------
- Flagging the same OSV id twice on the same package should update the
  existing flag (status resets to "open"), not create a duplicate row.
- Resolving a flag (Vulnerabilities page > Resolve) should flip its
  status badge from red "open" to green "resolved".
- Logging in as "dev" (password dev123) should hide the Vulnerabilities
  nav link and the Flag vulnerability panel entirely — only "admin"
  (password admin123) can see/use them.
